단계 설명

선택 전

도형이나 연결선을 선택하면 이름·설명·규칙 번호를 확인하고 수정할 수 있습니다.

규칙 번호와 설명도 BPMN 파일 안에 함께 저장됩니다.

수정하고 검토받는 순서
  1. 도형·선·설명을 수정합니다.
  2. 상단 BPMN 저장을 눌러 파일을 받습니다.
  3. 받은 .bpmn 파일을 대화에 첨부합니다.
  4. 규칙과 흐름을 함께 검토한 뒤 다음 판을 만듭니다.

공유·검토의 정본은 다운로드한 .bpmn 파일입니다. 임시 보관본은 같은 기기의 같은 브라우저에만 남습니다.

준비 중BPMN 2.0 · bpmn-js 18.30.1 · 파일 기반 편집

직접 수정하는 방법

  • 이동: 빈 곳을 끌거나 왼쪽 손도구를 사용합니다. % 단추는 읽기 크기, 전체 맞춤은 현재 계층 전체 보기입니다.
  • 추가: 왼쪽 도구에서 도형을 끌어 놓습니다.
  • 연결: 도형을 누른 뒤 오른쪽 작은 화살표를 끌어 다른 도형에 연결합니다.
  • 이름: 도형 또는 연결선을 두 번 누릅니다.
  • 설명: 도형을 한 번 누르고 오른쪽 설명·규칙을 고칩니다.
  • 상세 흐름: 접힌 하위 프로세스의 작은 ↘ 버튼 또는 오른쪽 ‘하위 흐름 열기’를 누릅니다.
  • 복귀: 왼쪽 위 경로 또는 ‘상위 흐름’을 누릅니다.
  • 저장: ‘BPMN 저장’으로 모든 계층이 담긴 .bpmn 파일을 다운로드합니다.

정교한 도형 편집은 마우스·트랙패드가 있는 PC에 적합합니다. 휴대폰에서는 열람·설명 수정·파일 저장이 가능합니다.
