# Artwork 업무 흐름 — 전체 프로세스 · Workflow · Step

공개 열람: https://aiopshwang.github.io/artwork-workflow-qs-20260929/process-design/?v=flow-5

전체판은 역할별 현행 업무와 자료 전달 관계를 보여 줍니다. 업무 상자를 선택하면 담당·업무명·업무 설명·입력값·산출물·업무 규칙을 읽을 수 있습니다. 솔루션과 관련된 업무에는 상세 Workflow를 여는 단추가 있습니다.

상세 Workflow에서 **현재 업무 / 도입 후 업무 / 변경점·기능**을 비교합니다. 각 Step을 선택하면 담당자, 입력, 하는 일, 산출물, 업무 규칙과 기존 기능 번호를 확인할 수 있습니다. Phase 표시는 개발 범위를 뜻하며 구현 완료를 뜻하지 않습니다.

## 읽는 방법

- 순서도를 잡아 끌어 이동하고, 검색으로 업무를 찾습니다.
- 업무를 선택하면 직접 이어진 업무와 연결선이 강조됩니다.
- 연결선을 누르면 이어진 업무로 이동합니다.
- 서로 연결되지 않은 선이 교차하면 작은 끊김으로 구분합니다. 실제 합류는 마름모와 화살표로 표시합니다.
- 상세 Workflow에서 **전체 업무 흐름**으로 돌아오면 앞서 보던 위치가 복원됩니다.
- 상세 Workflow와 Step의 주소를 복사해 같은 위치를 공유할 수 있습니다.
- 분기·합류는 ‘하나 선택’, ‘함께 진행’, ‘모두 대기’, ‘경로 합류’ 등으로 읽을 수 있게 표시합니다. 내려받는 파일은 표준 BPMN 의미를 유지합니다.

## 직접 수정하는 방법

1. 전체판의 **편집하기**, 또는 하위 흐름의 **이 흐름 편집하기**를 누릅니다.
2. 업무 이름·설명·도형·연결선을 수정합니다. 화면 이동은 손 도구를 사용합니다.
3. **수정본 다운로드**로 BPMN 파일을 보관합니다.
4. **BPMN 파일 열기**로 저장한 수정본을 다시 열 수 있습니다.
5. 수정한 BPMN 파일을 Codex 대화에 전달하면 업무 내용과 변경 관계를 검토할 수 있습니다.

편집한 파일이 공개본에 자동 반영되지는 않습니다. 서버 공동 저장은 연결되지 않았으며, 공개본 반영은 검토 후 별도로 진행합니다. 계층 간 업무 설명과 기능 연결은 카탈로그도 함께 갱신해야 하므로, BPMN 파일 하나를 고친 것만으로 모든 하위 설명이 자동 수정되는 것으로 보지 않습니다.

## 파일

- `artwork-overview.bpmn` / `artwork-overview.svg`: 전체 업무 흐름
- `workflows/catalog.json`: 상세 업무·Step·현재/목표 대응 및 기능 연결
- `workflows/WFxx-asis.bpmn` / `.svg`: 현재 업무 도면
- `workflows/WFxx-tobe.bpmn` / `.svg`: 도입 후 업무 도면
- `editor/`: 브라우저 BPMN 편집기

원본 개발 프로젝트와 고객 자료는 이 배포 작업에서 수정하지 않습니다. 업무 모델은 회의·URS·업무규칙장부 및 사용자와의 협의에 근거하며 고객의 최종 업무 검증과 소프트웨어 구현 검증을 대신하지 않습니다.
