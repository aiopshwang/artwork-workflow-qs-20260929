# Artwork 전체 업무 흐름 — 연결 표현 개선 2판

공개 열람: https://aiopshwang.github.io/artwork-workflow-qs-20260929/process-design/

`index.html`에서 마우스로 순서도를 잡아 끌어 이동할 수 있습니다. 업무 상자를 짧게 클릭하면 관련 업무와 연결선만 강조되고, 나머지는 회색으로 표시됩니다. 검색과 연결 업무 이동도 사용할 수 있습니다.

2판에서는 여러 경로가 모이는 지점을 별도로 표시하고, 의뢰사 Artwork 수령과 QS 검토, 외부 검토 요청과 결과 수령을 구분했습니다. 검정 실선은 업무 순서, 파란 점선은 회사 간 자료 전달, 갈색 실선은 수정·재검토로 돌아가는 경로입니다. 분기와 합류는 도형의 설명에서 조건을 확인할 수 있습니다. 기존 업무 경로와 미확인 질문은 유지했습니다.

## 수정하는 방법

1. 공개 화면 위의 **편집하기**를 누릅니다. 설치 없이 브라우저에서 현재 초안이 열립니다.
2. 업무 이름·설명·도형·연결선을 수정합니다. **손 도구**는 화면 이동, **선택·수정**은 도형 편집에 사용합니다.
3. **수정본 다운로드**를 눌러 BPMN 파일을 보관합니다.
4. 나중에 편집 화면의 **BPMN 파일 열기**로 저장한 파일을 다시 엽니다.

수정한 BPMN 파일을 Codex 대화에 첨부하면 업무 내용과 변경 사항을 검토할 수 있습니다. 공개본 반영은 별도로 진행합니다.

편집 내용은 해당 브라우저와 내려받은 파일에 보관됩니다. 서버 공동 저장이나 공개본 자동 변경 기능은 연결되지 않았습니다. 새 업무 초안과 편집 화면만 추가했으며 기존 순서도 파일들은 보존했습니다.
