아트워크 전체 업무 흐름 · 한 판에서 상세 순서도까지

1. 압축파일을 풀고 모든 파일을 같은 폴더에 둡니다.
2. index.html을 브라우저에서 엽니다. 전체 업무가 한 판에 이어져 있습니다.
3. 관계(자사/위탁/수탁)와 신규/개정 분기를 따라갑니다.
4. ＋ 표시가 있는 단계를 누르면 그 단계의 Archify 상세 순서도가 열립니다.
5. 개정 단계는 내부 변경/허가·규제/업체 통지/발주 전 차이 중 계기를 고릅니다.
6. 상세창의 '전체판으로'로 돌아오거나, 링크의 #step=...을 공유하면 그 단계가 바로 열립니다.
7. 축소·확대·전체 보기, 관계별 강조를 사용할 수 있습니다.

전체 업무판은 BPMN의 접힌 하위 프로세스 개념을 바탕으로 만든 탐색 화면이며, 엄밀한 BPMN 파일은 아닙니다. 13개 상세 순서도는 Archify workflow JSON으로 생성했고 Archify finalize의 검증·전달·검사·브라우저 검사를 통과했습니다. 초기 순서도 목록 화면은 이 한 판으로 대체했습니다.

QS팀 검증용 잠정 시안입니다. 생산 적합성 판정 주체, 수탁 신규의 확정 기준, 첫 발주를 포함한 완료 경계는 현업 확인 전입니다.
